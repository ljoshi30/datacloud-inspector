Data 360 Inspector

Floating toolkit for Salesforce Data Cloud — reveals API names on the mapping canvas, exports DLO/DMO fields, and exports segment rules to Sheets or Excel. Works on every Data 360 page type.

No install · works in any browser

Add the bookmarklet

  1. Show your bookmarks bar: ⌘⇧B on Mac  /  Ctrl⇧B on Windows.
  2. Drag this button to your bookmarks bar:   Data 360 Inspector
  3. Open any Data Cloud / Data 360 page in Salesforce and click the bookmark. A blue circle with a magnifying-glass icon appears in the bottom-right corner — click it to open the action menu.
  4. Click the bookmark again at any time to remove the tool.
The launcher sits in the bottom-right corner and never overlaps the Salesforce navigation. Click the 🔍 button to expand the menu; click outside or click it again to collapse.

Features by page

🔁 DLO → DMO Mapping canvas

  • API Tooltip — hover any field to see its API name in a tooltip; click to copy to clipboard
  • Pin API names — pins all API names directly on the canvas at once; click Unpin names to clear
  • Export — full DLO→DMO mapping table filterable by DMO · Copy for Sheets or Download CSV

🌐 Data Stream & DLO detail pages

  • Export Fields — all fields with API name, label, data type, status, and key qualifier · Copy for Sheets or Download CSV

🌐 DMO detail pages

  • Export Fields — Fields tab (API name, type, mapped status, key qualifier) and Relationships tab (related objects and join fields) · Copy for Sheets or Download XLS

🏁 Segment pages

  • Export Rules — reads all segment conditions live from the canvas across Include, Exclude, and Rank & Limit tabs
  • Copy for Sheets — rich HTML table with group structure, AND/OR joiners, and sub-filters; pastes into Google Sheets or Excel with full formatting
  • Download HTML — saves a self-contained file that opens in Excel or Sheets with colours, groups, and a metadata footer

📊 Data Explorer (DLO / DMO query view)

  • Columns — opens the Column Selector showing all available fields for the object, not just the handful SF shows by default
  • Available tab — search fields by name or label, sort A→Z / Z→A, select all / deselect all
  • Column Order tab — drag rows to reorder your selected columns before applying
  • Apply columns — applies your selection; SF re-fetches data for those columns; each column renders at 200 px wide with text clipped cleanly
  • Selection memory — reopening the Column Selector always shows your last applied set, not all fields — no need to re-select every time
  • Save set — saves current selection & order to browser storage (keyed per object per org, 90-day TTL); always overwrites the previous saved set
  • Restore saved — re-applies the saved set at any time with a visible spinner
  • Clear saved — removes the saved set for this object from browser storage
  • Export CSV — downloads all visible rows as a CSV with the current column set
  • Edit SOQL — full VS Code–style dark SOQL editor with syntax highlighting:
    • Opens pre-filled with a SELECT of your currently selected columns and a LIMIT 100
    • Inline autocomplete — type any character and a dropdown appears inside the editor showing matching field names (with type badge) and SOQL keywords; Tab or click to insert, Esc to dismiss
    • Syntax colours — keywords in blue, field names in fuchsia, strings in green, numbers in orange
    • Run — applies the SELECT fields as columns and respects the LIMIT (max 100, Data Cloud's limit); copy the query to use in Developer Console for WHERE filtering
    • Copy — copies the full SOQL to clipboard for Developer Console or Workbench
    • Reset — restores the original auto-generated query
Auto-restore: on the first Column Selector open after a page load, any saved set is automatically applied (spinner shown). On subsequent opens the picker shows your last applied columns — click Restore saved to re-apply the saved set explicitly.

WHERE clause note: The SOQL editor applies column selection and respects LIMIT. WHERE filtering is not supported through this tool — copy the query to Developer Console or Workbench to run WHERE clauses against Data Cloud.

All modals are draggable (grab the header) and resizable (drag the bottom-right corner).

Privacy & safety

  • Runs entirely in your browser tab using data the page has already loaded.
  • No API calls, no network requests, no data sent anywhere.
  • Nothing is stored — the tool disappears when you close or reload the tab.
  • Read-only: it never modifies your Salesforce data.
